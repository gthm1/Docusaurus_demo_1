# Installation Guide — Acme Corp

## Xmesh gateway setup

1. Mount the gateway with clear line-of-sight to end devices
2. Power on and wait for the status LED to turn solid blue
3. Add the gateway's serial number in your AlphaX Cloud workspace

## XVision camera setup

1. Connect the camera to PoE
2. Register the camera's MAC address in AlphaX Cloud
3. Assign a stream profile from the dashboard
