# Support Playbook

This is general internal-only documentation, not tied to any single customer.

## Escalation tiers

- **Tier 1** — Front-line support, handles Xmesh gateway connectivity and AlphaX Cloud login issues
- **Tier 2** — Firmware and provisioning issues, XVision camera stream failures
- **Tier 3** — Engineering, for platform-level AlphaX Cloud incidents

## On-call rotation

See the internal roster tool for the current on-call engineer. Do not share customer account credentials over unencrypted channels.

## Internal tools

- Provisioning console: internal-only, VPN required
- Device fleet dashboard: internal-only
